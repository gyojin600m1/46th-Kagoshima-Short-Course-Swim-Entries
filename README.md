# 第46回 鹿児島県短水路水泳記録会 エントリー確認（非公式）

2026年11月1日(日)／鹿児島市鴨池公園水泳プール（25m×8レーン）
兼 第49回JOC春季大会鹿児島県予選会

公開URL: https://gyojin600m1.github.io/46th-Kagoshima-Short-Course-Swim-Entries/

`index.html` 1ファイルだけで動く（外部通信は閲覧カウンターのみ。`file://` でもGitHub Pagesでもそのまま動く）。

## できること

- **選手** … 名前・ひらがな・チーム名で検索。カードに「⏰ 11:21・12:16」のように泳ぐ時刻の目安、開くと種目ごとに予想の組・レーン。
- **種目** … 種目ごとの出場者をエントリータイム順に。各行に時刻の目安と組。
- **日程** … 競技順序・開始予定時刻・公式の組数・休憩。
- **リレー** … 申込チーム。
- **組・レーン** … エントリータイムからの予想（8レーン・全年齢区分まとめてタイム順、第1組＝最も遅い組）。組ごとに時刻の目安。
- **当日プラン** … 選手を選ぶと、レースの時刻から補食・招集（10分前）・ダウンを逆算して1日ぶん並べる。
- **大会情報** … 日程・当日の手続き・年齢区分。

## データのもと

- 鹿児島県水泳連盟HP「エントリー一覧」（2026/10/03 公開・`20261101_003.pdf`）… 484名・個人983件・リレー9件。名前・所属・学年・種目・タイムは全件照合済み。
- 「二次要項（監督会議資料）」（2026/10/22 公開・`20261101_004_007.pdf`）… 種目ごとの開始予定時刻・組数・休憩・当日の手続き。
  個人種目の組数は全種目で申込数からの計算と一致。メルヘン鹿屋の10歳以下リレー（No.2・No.38）は二次要項で「組なし」なので、その旨を表示している。
- 男女はエントリー一覧に欄がないため、過去の大会の結果（男女別の種目）とチーム内の並び（男子→女子、それぞれ年齢の高い順）から判定。女子165名は二次要項の人数と一致。

## 時刻の目安の出し方

二次要項に載るのは種目ごとの開始時刻だけ。種目の持ち時間（次の種目の開始まで。休憩は除く）を、
各組の「いちばん遅いエントリータイム＋入れ替えの時間」で割り振って、組ごとの泳ぎ出しを出している
（入れ替えの時間＝（持ち時間 − 各組の最遅タイムの合計）÷ 組数。二次要項の時刻表もほぼこの作り）。
組・レーン自体が予想なので時刻も目安。招集に遅れないよう分は切り捨て。

データは `index.html` の `const DATA = /*__DATA__*/{…}` の1行（`program[].startTime / endTime / heats / breakAfter`、`meta.dayPlan` など）。
